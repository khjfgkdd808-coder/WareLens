# 1. 꼬여서 캐싱된 npm 임시 파일들을 강제로 완전히 비워버립니다.
npm cache clean --force

# 2. 캐시 지우고 찌꺼기가 남아있을지 모를 node_modules 폴더를 다시 한 번 완벽히 삭제
Remove-Item -Recurse -Force node_modules, package-lock.json

# 3. [★중요] 캐시 없이 깃허브 원본 서버에서 새 파일들을 100% 처음부터 새로 다운로드합니다.

백엔드 실행 ( zulu 21 ) 

sts 에서 file - import - Gradle - Existing Gradle Project( 선택 후 next) 

- Project root directory 가장 최상위폴더로 경로설정( 설정 후 finish )

# STS에서 Zulu 21 JDK 등록하기 ( 없으면 다운로드 )
--------------------------------------------------------------
https://www.azul.com/downloads/?package=jdk#zulu     

21.0.11+10
Azul Zulu: 21.50.19 Window x86 64-bit JDK 다운로드
---------------------------------------------------------------
   
STS 상단 메뉴에서 [Window] -> [Preferences]를 클릭

왼쪽 트리에서 Installed JREs 검색 후 클릭

오른쪽의 [Add...] 버튼 선택

[Standard VM]을 선택하고 [Next]

JRE home 항목에서 [Directory...] 버튼을 눌러 Zulu 21이 설치된 폴더(예: C:\Program Files\Zulu\zulu-21)를 찾아 선택

[Finish]를 눌러 등록한 후, 목록에서 Zulu 21을 체크하고 [Apply and Close]
